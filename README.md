# 면담 녹음 서비스

노트북에서 브라우저 녹음을 시작하고, 완료된 음성 파일을 프로젝트 폴더에 저장하는 로컬 웹 앱입니다.

## 실행 방법

Node.js 18 이상이 설치된 노트북에서 프로젝트 폴더를 열고 실행합니다.

```sh
npm start
```

브라우저에서 <http://127.0.0.1:4173> 을 엽니다. 마이크 사용을 허용해야 합니다.

## 저장 위치

- 녹음 파일: `data/recordings/`
- 기록 목록: `data/recordings.json`

두 위치 모두 이 프로젝트 폴더 안에 있습니다. 서버는 녹음을 메모리에 한꺼번에 모으지 않고 파일로 스트리밍해 저장하며, 기록 목록은 임시 파일을 쓴 뒤 교체합니다. 앱은 `127.0.0.1`에만 연결을 엽니다. 기본 녹음은 외부로 전송되지 않으며, 사용자가 보고서 생성을 요청한 경우에만 Groq API에 음성을 보내 전사와 요약을 수행합니다.

녹음 전에 안내 및 필요한 승인 절차 확인란을 선택해야 합니다. 녹음 중에는 일시 정지와 재개를 사용할 수 있습니다.

## Groq API 설정

서버 폴더의 `.env.local` 파일에 `GROQ_API_KEY=발급받은_API_키`를 설정하고 서버를 다시 시작합니다. 키는 서버에서만 읽으며 브라우저로 전달하지 않습니다. 이 파일은 Git에서 제외됩니다.

녹음 전에 자동 생성 확인란을 선택하면 저장 직후 Groq Whisper Turbo로 한국어 전사를 진행하고 Groq 텍스트 모델로 상담보고서 초안을 작성합니다. 확인란을 선택하지 않은 경우 저장된 녹음 옆의 **상담보고서 생성** 버튼을 눌러 개별 생성할 수 있습니다. 음성 파일의 무료 구간 크기 제한은 25MB이며, 한도를 넘거나 계정 제한에 도달하면 원본 녹음은 그대로 남고 오류 안내를 표시합니다. 보고서와 전사문은 `data/recordings.json` 및 `data/reports/`에 저장됩니다. AI 초안은 담당자가 반드시 검토하고 수정해야 합니다.

브라우저 탭이나 서버를 녹음 중 강제로 닫으면 미저장 녹음은 복구되지 않을 수 있으므로, 반드시 **녹음 종료**를 눌러 저장 완료 안내를 확인하세요.
